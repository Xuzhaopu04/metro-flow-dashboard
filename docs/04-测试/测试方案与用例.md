# 测试方案与用例

## 1. 范围

| 层次 | 覆盖 | 不覆盖 |
|------|------|--------|
| 单元测试 | 窗口切分、口径计算、消息解析、参数校验 | 前端交互 |
| 接口测试 | 四个 REST 接口的正常与异常返回 | 并发压力 |
| 集成测试 | 采集 → 计算 → 存储 → 接口 → 页面整链 | 多实例部署 |
| 手工测试 | 页面展示、断线恢复、异常数据表现 | 浏览器兼容性（只测 Chrome/Edge） |

## 2. 策略

- 能用自动化覆盖的逻辑一律写进 `tests/`，测试用 SQLite 与失效端口，不依赖外部服务；`pytest` 一条命令跑完。
- 依赖真实链路的场景（实时性、断线恢复）用手工步骤 + 截图留证。
- 异常数据用模拟器的 `--inject` 生成，不在测试代码里硬编码脏数据。

## 3. 环境

| 项 | 值 |
|----|-----|
| 系统 | Windows 11 / macOS 14 |
| Python | 3.11+ |
| 依赖 | 按 `requirements.txt` 锁定版本 |
| 数据 | `data/samples/sample_events.json`，20 条，覆盖 6 个站 |
| 自动化命令 | `pytest` |

## 4. 通过标准

1. 自动化用例全部通过；
2. 手工用例无阻塞级缺陷；
3. 已知缺陷有记录、有规避方案；
4. 接口返回结构与契约 v1.1 一致（字段名、类型、错误码）。

## 5. 用例

### 5.1 功能

| 编号 | 用例 | 步骤 | 预期 |
|------|------|------|------|
| TC-01 | 实时客流上屏 | 起容器、消费者、模拟器，打开页面 | 柱状图每秒变化，数字递增 |
| TC-02 | 站点排序 | 观察柱状图与排行 | 均按客流降序 |
| TC-03 | 线路筛选 | 点"1 号线" | 只显示 L1 站点，排行不受影响 |
| TC-04 | 趋势曲线 | 等待 30 秒 | 折线连续，时间轴按秒递增 |
| TC-05 | 排行统计 | 等待 5 分钟后比较柱状图累计 | 排行值与近 5 分钟累计一致 |
| TC-06 | 历史查询 | `GET /api/series?station_id=A01&minutes=5` | 只返回 A01 的点 |
| TC-07 | 样例回放 | `--replay data/samples/sample_events.json` | 两次回放结果一致 |

### 5.2 边界

| 编号 | 用例 | 步骤 | 预期 |
|------|------|------|------|
| TC-08 | 空数据 | 只起 Web 不起消费者 | 页面显示"暂无数据"，不报错 |
| TC-09 | 快照过期 | 停消费者 10 秒 | 页面转为暂无数据，接口仍 200 |
| TC-10 | 参数下界 | `minutes=1`、`top=1` | 200，返回单点/单条 |
| TC-11 | 参数上界 | `minutes=60`、`top=20` | 200 |
| TC-12 | 参数越界 | `minutes=0`、`minutes=61`、`top=21` | 400，`INVALID_PARAM` |
| TC-13 | 参数类型错 | `minutes=abc` | 400，message 带上收到的值 |
| TC-14 | 未知路径 | `GET /api/nothing` | 404，`NOT_FOUND`，JSON 不是 HTML |

### 5.3 异常

| 编号 | 用例 | 步骤 | 预期 |
|------|------|------|------|
| TC-15 | 缺字段事件 | `--inject 0.1` 运行 2 分钟 | 非法条数上涨，客流不异常，进程不退出 |
| TC-16 | 乱序事件 | 同上 | 迟到条数上涨，当前秒客流不虚高 |
| TC-17 | 脏消息 | 手工 `XADD` 一条非 JSON | 计 1 条非法，其余照常 |
| TC-18 | Redis 不可用 | 停 redis 容器 | 接口返回空快照；消费者与模拟器提示后退出 |
| TC-19 | MySQL 不可用 | 停 mysql 容器 | 消费者继续写快照，只告警一次；实时功能可用 |
| TC-20 | 消费者重启 | 停 30 秒再启 | 事件不重复计入，快照恢复 |
| TC-21 | 重复落库 | 同一窗口重放两次 | `metric_window` 不出现重复行 |

### 5.4 界面

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-22 | 告警横幅 | 客流超 100 人次/秒出现红色提示，回落后消失 |
| TC-23 | 断线提示 | 停 Web 服务，底部显示"连接中断，正在重试"；恢复后自动续上 |
| TC-24 | 窗口缩放 | 图表随窗口自适应，不出现空白或错位 |

## 6. 自动化对应关系

| 用例 | 自动化位置 |
|------|-----------|
| TC-06、TC-10～TC-14 | `tests/test_api.py` |
| TC-15、TC-16、TC-21 的口径部分 | `tests/test_metrics.py` |
| TC-17 | `tests/test_consumer.py` |
| TC-01～TC-05、TC-18～TC-20、TC-22～TC-24 | 手工执行，截图留档 |

## 7. 遗留问题

- 并发与性能未测（选题要求只到"验证实时性"）；
- 只有一个人在 Windows 上完整跑过，跨平台差异未覆盖。
