## 填写说明

- **工具**：写具体名字（Cursor / Copilot / 通义灵码 / 文心快码 / ChatGPT），不要只写"AI"。
- **环节**：需求分析 / 系统设计 / 编码 / 测试 / 文档。
- **让它做了什么**：一句话说清任务，不写"帮我写代码"。
- **人工改了什么**：评分重点，写具体动作——补了哪个分支、换了哪个字段、删了哪段、为什么删。
- **采纳程度**：直接采用 / 部分采纳 / 仅参考 / 否决。
