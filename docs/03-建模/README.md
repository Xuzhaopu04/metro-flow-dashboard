## 图源格式说明

用例图 / 活动图 / 域模型按《需求工程建模规范》重绘过一轮（2026-11-23）：

- **4 张用例图一律用坐标化 SVG**（`02`～`05`）。`03`、`04` 是参与者 ≥4 超自动布局阈值（06 §1）；
  `02`、`05` 虽在阈值内，但自动布局会把 `«extend»`/`扩展点` 标签挤到虚线中间、把 UC-18 的标签甩到
  参与者旁，且参与者画不出与 `03`、`04` 一致的火柴人。四张统一坐标化后符号、配色、字号才真的一致；
- 用例图的权威描述是各自 SVG 头部的 XML 注释（节点清单 + 边清单 + 布局分区 + 例外说明），
  改图直接调坐标，不要改回 PlantUML；
- 活动图的活动名以 `UC-xx 步n` 为前缀，`n` 取自用例表主事件流步号，可双向核对；
- 域模型的两端都标多重性，关联名下附角色名（`line / station`）。
- **`43` 包图用坐标化 SVG**：包图不在《需求工程建模规范》四类产物内（§1 明确不适用），
  但 `06` §1 的换工具判据同样成立——自动布局把 `api → simulator` 这条跨层依赖拉成穿过
  `stream` 的斜线、包内构件排成大块空白、整图 2.3:1 过宽插不进版心。现改为四层竖向堆叠，
  跨层依赖走左侧专用通道；包清单、依赖清单与"为什么这么画"全写在 SVG 头注释里。
- **`44` 是程序级活动图，活动名以函数名为前缀**（`run_window` / `split_ready` / `aggregate_window`），
  编号是代码执行顺序，不对应用例表步号——用例级的那三张（`06`～`08`）仍按 `UC-xx 步n` 编号。
  2.2.2「关键程序逻辑」要的就是"调用哪个方法"，与 references/03 §4-7「不画系统内部实现」相反，
  理由写在图头注释里；两张图的分工也在那里写清，避免被当成重复引用。
- **鲁棒图（15～18、23～36）图源一律是坐标化 SVG**，头部注释写着节点表、边表、覆盖范围与假设；
  控制内部的步子（取时钟、换算式、唯一键冲突忽略）不单独画线，写进相邻消息名或图注；
  边清单的消息编号就是活动推进顺序，逐条对应用例表步号，
  所以图里只有四个符号：左竖线圆=边界、顶弧圆=控制、下横线圆=实体、右侧方框=外部系统；
- **序列图（19～22、37～42）用 PlantUML**，`boundary` / `control` / `entity` / `collections`
  关键字画出与鲁棒图一致的三元素标记，`hide footbox` + `scale 1.7` 保证插入 A4 后字号可读；
- **外部系统当参与者是刻意的**：`Redis Stream`、`MySQL`、下游模块出现在用例图里，是按
  "模块视角下它们是系统之外、与本模块有交互的协作方"处理的，一律标 `«actor»`，不当成
  本系统的内部模块。这条已与 `docs/01-需求/用例表.md` 的角色列表对齐。

## 导出图

`docs/03-建模/图/` 下是导出好的 PNG，直接插进报告即可。改了源文件要重新导出，别让图和源文件对不上。

## 怎么出图

方式一：VS Code 装 `PlantUML` 插件，打开 `.puml` 按 `Alt+D` 预览，右键导出 PNG。

方式二：命令行（需要 Java 与 plantuml.jar）：

```bash
java -jar plantuml.jar -tpng docs/03-建模/*.puml -o 图
```

方式三：坐标化 SVG 用浏览器截图导出 2x PNG（`--window-size` 必须等于该 SVG 的 `width/height`，
否则四周留白或右侧裁切；`file://` 里的中文路径段要 URL 编码）：

```bash
# 02 是 1700×760，03、04 是 1700×780，05 是 1700×940，43 是 1080×840
msedge --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=2 \
  --screenshot=图/03-用例图-实时计算.png --window-size=1700,780 "file:///.../03-用例图-实时计算.svg"
```

方式四：贴到在线编辑器渲染，用于临时检查语法。

## 约定

- 一个文件一张图，文件名前缀是编号，导出图与源文件同名。
- 改图要同步改 `docs/01-需求/用例表.md` 与 `docs/02-设计/` 的文字，避免图文不一致。
- 图里的模块名与代码目录保持一致（`simulator/`、`stream/`、`api/`、`web/`），评审时能直接对上。
