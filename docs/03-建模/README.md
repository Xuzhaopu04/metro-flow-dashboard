## 图源格式说明

用例图 / 活动图 / 域模型按《需求工程建模规范》重绘过一轮（2026-11-23）：

- **参与者 ≤3 且用例 ≤7** 的用例图用 PlantUML（`.puml`），自动布局够用；
- **参与者 ≥4** 的用例图（`03`、`04`）改用**坐标化 SVG**——PlantUML 在这种规模下会把
  参与者排进框内、连线绕到标题上。这两张图的权威描述是各自 SVG 头部的 XML 注释
  （节点清单 + 边清单），改图直接调坐标；
- 活动图的活动名以 `UC-xx 步n` 为前缀，`n` 取自用例表主事件流步号，可双向核对；
- 域模型的两端都标多重性，关联名下附角色名（`line / station`）。
- **外部系统当参与者是刻意的**：`Redis Stream`、`MySQL`、下游模块出现在用例图里，是按
  "模块视角下它们是系统之外、与本模块有交互的协作方"处理的，一律标 `«actor»`，不当成
  本系统的内部模块。这条已与 `docs/01-需求/用例表.md` 的角色列表对齐。

## 导出图

`docs/03-建模/图/` 下是导出好的 PNG，直接插进报告即可。改了源文件要重新导出，别让图和源文件对不上。

## 怎么出图

方式一：VS Code 装 `PlantUML` 插件，打开 `.puml` 按 `Alt+D` 预览，右键导出 PNG。

方式二：命令行（需要 Java 与 plantuml.jar）：

```bash
java -jar plantuml.jar -tpng docs/03-建模/*.puml -o 图
```

方式三：坐标化 SVG 用浏览器截图导出 2x PNG（尺寸必须等于 SVG 的 width/height，否则四周留白）：

```bash
msedge --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=2 \
  --screenshot=图/03-用例图-实时计算.png --window-size=1700,780 "file:///.../03-用例图-实时计算.svg"
```

方式四：贴到在线编辑器渲染，用于临时检查语法。

## 约定

- 一个文件一张图，文件名前缀是编号，导出图与源文件同名。
- 改图要同步改 `docs/01-需求/用例表.md` 与 `docs/02-设计/` 的文字，避免图文不一致。
- 图里的模块名与代码目录保持一致（`simulator/`、`stream/`、`api/`、`web/`），评审时能直接对上。
