## 导出图

`docs/03-建模/图/` 下是导出好的 PNG，直接插进报告即可。改了 `.puml` 要重新导出，别让图和源文件对不上。

## 怎么出图

方式一：VS Code 装 `PlantUML` 插件，打开 `.puml` 按 `Alt+D` 预览，右键导出 PNG。

方式二：命令行（需要 Java 与 plantuml.jar）：

```bash
java -jar plantuml.jar -tpng docs/03-建模/*.puml -o 图
```

方式三：贴到在线编辑器渲染，用于临时检查语法。

## 约定

- 一个文件一张图，文件名前缀是编号，导出图与源文件同名。
- 改图要同步改 `docs/01-需求/用例表.md` 与 `docs/02-设计/` 的文字，避免图文不一致。
- 图里的模块名与代码目录保持一致（`simulator/`、`stream/`、`api/`、`web/`），评审时能直接对上。
