帮助

这块屏只回答当下三件事：哪个站人多、有没有超阈值、数据还可不可信。

当前秒乘降量当前 1 秒窗口内进站 + 出站的 passengers 之和，每秒清零重算
区间累计查询页对所选时间范围的逐秒/分钟/小时点求和，是前端汇总，不是“今日累计”
今日累计查询页顶部“今日汇总”，来自 /api/summary/today，起点为项目时区当日 0 点
方向进站/出站由契约 v1.3 提供；计算端双写完成前为 null，页面显示“—”，不拿合计顶替
活跃站点当前窗口内有数据的站点数
迟到事件时间早于窗口起点 2 秒以上，只计数，不计入客流
非法缺必填字段、类型不对、JSON 解析失败
排行与趋势排行取最近 5 分钟累计降序；趋势与查询支持秒/分钟/小时粒度，最多回溯 60 分钟或今日
窗口按处理时间切、迟到不回补；快照 TTL 5 秒，消费者停 5 秒以上页面就显示“暂无数据”。阈值走服务端配置，页面只照下发的值渲染。
页面现象多半是什么先做什么
页脚变黄数据停更 10—30 秒，消费者重连中看消费者终端最后一行
页脚变红消费者退出，或 Redis 断了查 metric:snapshot 是否还在
右上角连接中断接口请求失败，服务没起或端口不通直接打开 /api/snapshot
有数字、柱子全空快照结构异常或接口降级看接口返回的原始 JSON
迟到或非法持续涨时钟不同步，或上游数据变脏对时，再看消费者日志

处置顺序

  1. 看页脚与连接状态，先分清是没数据还是连不上。
  2. 打开 /api/snapshot：空结构说明没快照，有数据说明问题在本页。
  3. 执行 redis-cli GET metric:snapshot：键在查接口，键不在查消费者。
  4. 按 Redis/MySQL → 消费者 → 模拟器 → 页面 的顺序重启，再用固定样例回放验证。

链路：模拟器 → gate_events → 消费者 → 快照/明细表 → 接口 → 本页。停在哪一层，页脚和连接状态会先给信号。

为什么当前秒乘降量每秒都归零？

它是 1 秒窗口值，不是累计值。要看今日累计请切到“客流查询”，顶部今日汇总来自 /api/summary/today。

排行有数字，柱子却是 0？

排行看最近 5 分钟，柱子只看当前这一秒。刚回放完也会这样，5 分钟后自然消失。

告警阈值在哪里改？

改环境变量 ALERT_THRESHOLD 后重启服务端；页面直接使用接口下发的值。

能看到进站和出站分开统计吗？

接口已支持 direction=in / out；计算端双写完成前返回 null，页面显示“—”，不会把合计拆成进站或出站。
